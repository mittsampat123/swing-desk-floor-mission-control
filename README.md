# Swing Desk: Floor + Mission Control

A rules-based options desk that runs inside Claude, with a live numbers
dashboard (Mission Control), an animated dealing room (The Floor), a
built-in risk officer, a five-seat council that must approve every
ticket, a shared desk memory, and a weekly learning loop.

## How to start

1. Open this repository in Claude Code: at claude.ai/code choose "open a
   repository" and paste this repo's link, or clone it and run Claude
   Code in the folder.
2. Say hello. Claude reads `CLAUDE.md`, sees the desk is not set up yet,
   and starts asking you questions: which account, what options
   strategy you want it to execute, your risk caps. It fills in the
   rules from your answers, publishes your Mission Control and Floor
   pages, seeds the desk's memory, offers a three-year backtest, does a
   dry run with you, and sets up the schedule.
3. Open the Floor link it gives you on your phone and watch.

Nothing trades until you have typed your own authorization paragraph,
and nothing ever trades outside the caps you set.

GUIDE.md explains every screen and every step in detail, so you know
what is coming.

## What is here

| File | Role |
|---|---|
| `CLAUDE.md` | What Claude does when this repository is opened: the setup interview and the running of the desk. |
| `GUIDE.md` | The tour of every screen and the setup steps, for you to read. |
| `swing-desk-prompts.md` | The prompt pack: constitution (PROMPT 0) with a STRATEGY block you fill, the stage prompts, the schedule. |
| `swing-desk.html` | Mission Control source. Publish it as your own private artifact. |
| `swing-desk-floor.html` | The Floor source. Publish it as your own private artifact. |
| `desk_indicators.py` | Indicator engine, standard-library Python. Moving averages, RSI, ADX, ATR, Williams %R variants, market-structure tools. |
| `build_routine.py` | Assembles the one scheduled-routine prompt from the prompt pack and the engine. |
| `swing-desk-routine-prompt.md`, `swing-desk-routine.json` | Generated by the script above. Regenerate after any edit. |

## Requirements

- A Robinhood account with the options level your strategy needs and
  agentic (Claude) trading enabled on exactly one account.
- A Claude plan with Claude Code, Artifacts and routines.
- Python 3 on the machine you set up from.

## Not advice

Nothing here is investment advice and nobody involved is a licensed
adviser. Defined-risk short option strategies win often and lose big;
the risk caps exist for the losing weeks. Test your rules before you
trade them, read the worst trades, and decide for yourself.
